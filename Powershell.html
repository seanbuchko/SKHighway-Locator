What This Script Does

This Windows PowerShell script scans a selected folder and all subfolders for JPEG photos and generates:

  • photo_metadata.csv – GPS, date taken, parsed title fields, and Excel hyperlinks
  • photo_map.kml – Google Earth placemarks with embedded images
Portable Output: All links use relative paths. You can move the entire project folder without breaking CSV links or KML images.

Download Script (.ps1)

General Workflow (Recommended)

  1. Take photos using the SKHighway Locator app
  2. Transfer photos to Windows without compressing them
  3. Ensure photos are JPEG (.jpg/.jpeg)
  4. Place all photos inside a single root folder (subfolders allowed)
  5. Run the PowerShell script and select the root folder
  6. Open the generated CSV in Excel and KML in Google Earth

Running the Script in PowerShell

PowerShell Console

  1. Download the script
  2. Right-click → Properties → Unblock
  3. Open PowerShell and run:
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
Unblock-File "C:\Path\To\SKHighway Locator Powershell Script.ps1"
powershell -ExecutionPolicy Bypass -File "C:\Path\To\SKHighway Locator Powershell Script.ps1"

PowerShell ISE

  1. Open PowerShell ISE
  2. File → Open → select the script
  3. Press F5 to run
  4. Select your photo root folder when prompted
If the folder picker does not appear, make sure ISE is the active window and press F5 again.
