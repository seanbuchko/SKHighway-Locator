PowerShell Script: Photo CSV + KML Generator

This Windows PowerShell script scans a selected folder and all subfolders for JPEG photos, reads EXIF GPS and title metadata, and generates:

  • photo_metadata.csv — includes columns for FileName, PhotoFolder (relative), DateTaken, Latitude, Longitude, and labeled fields parsed from the photo Title (Road, Station, Offset, Accuracy, Note), plus an Excel-friendly hyperlink (=HYPERLINK("...","Open Photo")).
  • photo_map.kml — a Google Earth placemark file where each pin uses the photo’s GPS coordinates and shows the image and details in the description using relative paths.
Relative paths supported: You can move the entire root folder (photos + CSV + KML) anywhere—links and images will continue to work.

How to Use (Windows)

  1. Click the Download PowerShell Script button above and save the file (e.g., to your Desktop).
  2. Right‑click the downloaded file → Properties → check Unblock (if present) → OK.
  3. Open Windows PowerShell (or PowerShell in Windows) and run: 
    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
Unblock-File -Path "C:\Path\To\SKHighway Locator Powershell Script.ps1"
powershell -ExecutionPolicy Bypass -File "C:\Path\To\SKHighway Locator Powershell Script.ps1"
  4. When prompted, select the root folder containing your photos. The script will search subfolders automatically.
  5. Open the generated photo_metadata.csv in Excel (double‑click to allow formulas to evaluate) and load photo_map.kml in Google Earth.

Requirements

  • Windows 10/11 with PowerShell (5.1 or 7.x on Windows)
  • JPEG photos with EXIF GPS for map pins (non‑GPS photos still appear in CSV)
  • Optional Title metadata in the format: Road: ..., Station: ..., Offset: ..., Accuracy: ..., Note: ...

Notes

  • CSV hyperlinks are relative (e.g., Subfolder\IMG_0005.JPG) and work when opened directly in Excel.
  • KML image references are relative (e.g., Subfolder/IMG_0005.JPG) so photos display in Google Earth.
  • The script only scans .jpg / .jpeg. If you need .png or others, contact us.
