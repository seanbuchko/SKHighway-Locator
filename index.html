PowerShell Script: Photo CSV + KML Generator

This Windows PowerShell script scans a selected folder and all subfolders for JPEG photos, reads EXIF GPS and title metadata, and generates:

  • photo_metadata.csv — columns for FileName, PhotoFolder (relative), DateTaken, Latitude, Longitude, and labeled fields parsed from the photo Title (Road, Station, Offset, Accuracy, Note), plus an Excel-friendly hyperlink (=HYPERLINK("...","Open Photo")).
  • photo_map.kml — a Google Earth placemark file where each pin uses the photo’s GPS coordinates and shows the image and details in the description using relative paths.
Portable by design: The CSV hyperlinks and KML image references use relative paths. You can move the entire root folder (photos + CSV + KML) anywhere—links and images will still work.

How to Run (PowerShell Console)

  1. Download and save the script file (e.g., to your Desktop).
  2. Right‑click the file → Properties → check Unblock (if present) → OK.
  3. Open Windows PowerShell (or PowerShell) and run: 
    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
Unblock-File -Path "C:\Path\To\SKHighway Locator Powershell Script.ps1"
powershell -ExecutionPolicy Bypass -File "C:\Path\To\SKHighway Locator Powershell Script.ps1"
  4. When prompted, select the root folder containing your photos. The script will search subfolders automatically.
  5. Open photo_metadata.csv in Excel and photo_map.kml in Google Earth.

How to Run with PowerShell ISE

PowerShell ISE provides a GUI for editing and running scripts. Follow these steps:

  1. Download the script:
    Download PowerShell Script (.ps1)
  2. Unblock the file (Windows may mark downloaded scripts as blocked):
    • Right‑click the file → Properties → check Unblock → OK.
    • Or run in PowerShell: Unblock-File -Path "C:\Path\To\SKHighway Locator Powershell Script.ps1"
  3. Open PowerShell ISE:
    • Press Win, type PowerShell ISE, and open the app.
    • (Optional) Run ISE as Administrator if you need to change the execution policy for all users.
  4. Ensure scripts can run (recommended setting for your user): 
    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
  5. Load the script into ISE:
    • File → Open → select SKHighway Locator Powershell Script.ps1.
  6. Run the script:
    • Press F5 or click Run Script.
    • A folder picker dialog will appear on top. You can paste a path or browse to the folder to use as the root.
  7. Results:
    • The script scans the selected folder and all subfolders for .jpg / .jpeg files.
    • It creates photo_metadata.csv and photo_map.kml in the selected root folder.
    • Open the CSV in Excel (double‑click to allow formulas to evaluate) and load the KML in Google Earth.
Troubleshooting ISE:
  • If the folder dialog doesn’t appear, make sure ISE is the active window and press F5 again. The script shows a TopMost owner window to bring the picker in front.
  • If you see an execution policy error, re‑run: Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned in ISE’s console pane.

Using SKHighway Locator Photos on Windows (Transfer & Process)

The SKHighway Locator app stores photos with GPS coordinates in EXIF and a structured Title like: Road: CS 102-27, Station: 9+933, Offset: 11 m Right, Accuracy: ±3 m, Note: photo of stream facing E. After transferring these photos to your Windows PC, the PowerShell script will read that metadata and produce the CSV and KML in the root folder you select.

1) Transfer Photos From Your Phone (Preserve Metadata)

  • USB cable (recommended): Connect your phone to Windows and copy the photos directly into a folder. This typically preserves EXIF and Title metadata.
  • OneDrive / Google Drive: Sync or upload the photos, then download to your PC. Ensure you download the original files to keep metadata.
  • iCloud for Windows: Use iCloud Photos to access originals and copy them to a local folder.
  • Avoid “compressed” exports: Some messaging apps or social platforms strip or compress images and remove metadata—do not use them for transferring project photos.

2) File Formats (HEIC vs JPEG)

  • The script scans only .jpg / .jpeg. If your iPhone saves photos as HEIC, convert to JPEG before running the script.
  • Tip for iPhone: in Settings → Camera → Formats, choose Most Compatible to save new photos as JPEG.
  • On Windows, you can convert HEIC to JPEG using the Photos app or any reliable converter (ensure EXIF/GPS is preserved).

3) Organize Your Root Folder

  • Create a root folder (e.g., C:\Projects\SKHwy102\Photos) and copy all project photos into it. Subfolders are allowed.
  • Do not rename files during transfer if filenames are referenced elsewhere.
  • You can place the script anywhere; when you run it, you’ll select the root folder you created.

4) Run the PowerShell Script

  • Use the instructions above (Console or ISE) to run the script.
  • When prompted, select your root folder. The script will:
    • Search all subfolders for .jpg/.jpeg.
    • Read EXIF GPS and Title metadata (Road/Station/Offset/Accuracy/Note).
    • Create photo_metadata.csv and photo_map.kml in the root folder.

5) Use the Outputs

  • CSV in Excel: The PhotoLink column uses formulas like =HYPERLINK("Subfolder\IMG_0005.JPG","Open Photo"). Click to open the photo in Windows.
  • KML in Google Earth: Each placemark shows the image and a text block with file/folder and Title fields. Paths are relative, so the KML remains portable with the folder.

Troubleshooting

  • No GPS? Some photos may lack EXIF GPS—those still appear in the CSV but won’t create map pins.
  • Images not showing in KML: Ensure the KML and the photo folders remain together and that you didn’t move individual subfolders without the KML.
  • Title fields missing: Confirm your transfer method preserved metadata; USB cable and cloud “original” downloads typically keep EXIF and Title intact.
  • HEIC files: Convert to JPEG with metadata preserved, or set the camera to save JPEG directly.
